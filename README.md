
This Python script has made to work with **Microsoft Windows ** environment.

The default port has chosen to **COM3**, so you can ***change*** it in the code as your need.

All **Standard baud rate speeds** are written in the code and are ready to be tested.

## Usage
just run 
> `python finder.py`

## Requirements
Make sure you install all the requirements before running the code:
> `pip install serial ctypes`
